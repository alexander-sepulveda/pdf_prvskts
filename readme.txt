Probabilistic Modeling and Inverse Design of Perovskite Solar Cells



Project Overview.
The objective of this project is to model Perovskite Solar Cells (PSCs) using a Gaussian Mixture Model (GMM) to approximate the joint probability density function of device parameters. Unlike standard discriminative models, this generative approach enables a unified framework for:
* Data Analysis: Clustering and interpretation of device performance.
* Data Generation: Creating synthetic, plausible device configurations.
* Inverse Design: Estimating optimal experimental synthesis conditions for a specific target Power Conversion Efficiency (PCE).



Methodology.
The workflow proceeds in three main stages:
* Feature Extraction: The absorber material is encoded into a dense 4-dimensional vector using Local Linear Embedding (LLE) to handle high-dimensional compositional data.
* Dataset Construction: These material embeddings are combined with synthesis descriptors (processing parameters) derived from the Perovskite Database Project.
* Probabilistic Modeling: A GMM is trained on this combined dataset. The model is then used for regression, conditional generation, and as an initialization step for an optimization algorithm to solve the Inverse Design problem.



Data Availability.
The processed dataset required to run these scripts can be downloaded from Zenodo: https://doi.org/10.5281/zenodo.16809654



Programs in scripts/.
* Data Preprocessing
  - LLE_prvskt_material.py: Generates the material representation using Local Linear Embedding (LLE).
  - synthesis_descriptors.py: Constructs the final dataset by merging LLE material vectors with synthesis descriptors.

* Modeling & Analysis
  - gmm_modelling.py: Trains the GMM and performs cross-validation to determine optimal hyperparameters.
  - gmm_final_testing.py: Deploys the final model and evaluates performance on unseen test data.
  - XGBoost_modelling.py: Trains an XGBoost regressor to benchmark against the GMM results.
  - interpreta.py: Analyzes and visualizes the latent clusters discovered by the GMM.
  
* Generative Tasks & Inverse Design.
  - pdf_full_gen.py: Performs full data generation and compares the statistical quality against data generated by GANs.
  - conditional_generator.py: Demonstrates conditional sampling (generating synthesis parameters given partial information, such as a known material).
  - inversion.py: Executes the Inverse Design pipeline, estimating experimental conditions required to achieve a target PCE.

* Tutorials/Toys
  - toy_LLE.py: A simplified example demonstrating how materials are mapped to lower-dimensional spaces using LLE.
